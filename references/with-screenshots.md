# 附截图版

截图只放在它所解释的步骤之后。每张图前说明“看哪里/做什么”，图后用一句图注指出关键区域。替代文字应描述界面与操作目的，不写“图片1”。连续截图较多时按步骤拆开，避免图片墙。

不得伪造未提供的截图。缺图时在 Markdown 写 `> 【待补截图：具体界面与应展示内容】`，HTML 渲染为提示卡片。发布前检查本地图片路径：公众号无法从读者设备访问本地文件，应先上传到公众号素材库或替换为可访问 URL。

图片内联样式至少包含：`display:block;max-width:100%;height:auto;margin:14px auto 6px;border-radius:8px;border:1px solid #e5e7eb;`。
